# Support

Thanks for using the Example Voting App. Here is where to get help.

## Bugs and problems with this app

Open an issue in this repository's [issue tracker](https://github.com/tryreplicas/example-voting-app/issues). Please use the issue template and include the steps to reproduce the problem, what you expected, and what happened.

## Problems with Docker itself

If the bug is in Docker and not in these labs, file it in the [Docker repo](https://github.com/docker/docker).

## General questions

For help with Docker, Compose, Swarm, or Kubernetes in general, try:

- The [Docker Forums](https://forums.docker.com/)
- The Docker Community Slack. You can join through the [Docker Community](http://dockr.ly/MeetUp) signup.

## Maintainers

The maintainers listed in [MAINTAINERS](MAINTAINERS) maintain this project. Please do not send support requests straight to them by email. Use the issue tracker so others can find the answer too.
