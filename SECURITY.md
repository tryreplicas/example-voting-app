# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues, pull requests, or discussions.

Instead, report them privately using GitHub's private vulnerability reporting:

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Fill in the form and submit it.

Only the repository maintainers can see private reports.

## What to include

To help us understand and fix the problem, please include as much of the following as you can:

- The affected component (for example `vote`, `result`, `worker`, or the deployment files) and the version or commit
- A description of the vulnerability and its potential impact
- Step-by-step instructions to reproduce it
- Any proof-of-concept code, logs, or screenshots
- Any suggested fix or mitigation, if you have one
